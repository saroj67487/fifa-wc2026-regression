# How to run (from the project folder)
#
# 1. Create a virtual environment
#      python -m venv .venv
#
# 2. Activate it
#      macOS / Linux:        source .venv/bin/activate
#      Windows (PowerShell): .venv\Scripts\Activate.ps1
#      Windows (cmd):        .venv\Scripts\activate.bat
#
# 3. Install the packages below
#      pip install -r requirements.txt
#
# 4. Run both models (2.1 and 2.2)
#      python main.py
#
# 5. (Optional) Run the tests
#      macOS / Linux:        PYTHONPATH=src python -m unittest discover -s tests -t .
#      Windows (PowerShell): $env:PYTHONPATH="src"; python -m unittest discover -s tests -t .
#
# 6. When finished, leave the virtual environment
#      deactivate
